# Input and policy refusal blocker

The census entries pointing here are not missing publication rungs. They are
closed by evidence that the request violates an existing operation contract:
the model is not a valid solid in the required assurance class, a malformed or
non-finite proof input cannot be interpreted, or the configured finite work
policy cannot admit the operation.

The required operator event is one of: repair or replace the source model,
select an operation whose dimensional contract accepts the model, or submit a
larger explicit work allowance. Kernel code must retain the typed refusal and
failure atomicity. Removing validation, coercing the operand into another
class, or silently raising a session limit is not a conversion.

If a concrete valid input later proves that one of these entries is actually a
missing mathematical class, move that entry back to `open` in the same commit
as its independent pin fixture. Do not broaden this blocker by analogy.
